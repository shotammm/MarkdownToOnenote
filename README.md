## MarkdownToOnenote

ローカルで動作する、Markdown を OneNote 向け / Slack 向けに変換するシンプルなツールです。

### 使い方

1. `index.html` をブラウザで開きます（ダブルクリックで OK です）。
2. 左側のテキストエリアに Markdown を貼り付けると、右側に HTML プレビューと HTML ソースがリアルタイムに表示されます。
3. 「OneNote用としてコピー」ボタンで、リッチテキスト（HTML）をクリップボードにコピーします。
4. 「Slack用としてコピー」ボタンで、Slack向けに整形したテキストをクリップボードにコピーします。
5. OneNote(Windows版) もしくは Slack に貼り付けます。

### 対応している要素

- 見出し（`#` ～ `######`）
- 箇条書き・番号付きリスト
- 太字・斜体
- リンク（`[text](url)`）
- テーブル
